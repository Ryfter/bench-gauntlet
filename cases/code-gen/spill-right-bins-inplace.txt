Write a function spill_right_inplace(bins: list[int], limit: int) -> None that mutates bins in place. Process indices from left to right for every index i in 0 .. len(bins)-2: if bins[i] is strictly greater than limit, add (bins[i] - limit) to bins[i+1], then set bins[i] to limit. Because overflow is added to the next bin before that bin is processed, overflow can cascade through multiple bins in a single left-to-right pass. The final bin is never reduced by this process ΓÇö if it ends above limit, leave it above limit. Values already <= limit are left unchanged and never spill (including zeros and negatives). Assume limit >= 0 always. An empty list is a no-op. A single-element list is never reduced. The function must mutate the original list object and must return None ΓÇö not the list, not a copy.
