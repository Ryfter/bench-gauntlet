Write a function consecutive_runs(text: str) that returns a generator yielding (character, run_length) pairs for each maximal contiguous run of the same character in text, left to right. For example, three a's then two b's then one c yields three pairs in that order. A single character is a run of length 1 and must be emitted. The empty string yields no pairs. Characters are compared by exact equality (case-sensitive; Unicode code points are ordinary characters). Surface constraint: the function must be a generator function that yields pairs lazily ΓÇö it must not return a fully built list (or other concrete sequence) of pairs. Callers will treat the return value as an iterator.
