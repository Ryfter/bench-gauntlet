Write a function step_gaps(series: list[int]) that returns a generator yielding the successive adjacent differences of series: for each index i from 1 to len(series)-1 inclusive, yield (series[i] - series[i-1]) in that order. Differences must keep their sign (a drop yields a negative number). An empty list and a single-element list both yield nothing. Surface constraint: the function must be a generator function that yields differences lazily ΓÇö it must not return a fully built list (or other concrete sequence) of differences. Callers will treat the return value as an iterator and may consume only a prefix of a long series.
