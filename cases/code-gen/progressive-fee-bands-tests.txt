- weight is an int (grams). If weight <= 0, return 0 regardless of brackets.
- brackets is a list of (capacity, rate) pairs of ints, applied in order as progressive bands.

- If brackets is empty, return 0 for any weight.
- If non-last capacities are 0, those bands contribute nothing and remaining proceeds to later bands.
- Return the total fee as an int. Pure; no mutation of brackets.

    if weight <= 0 or not brackets:
        return 0
    rem = weight

            if rem <= cap:
                return weight * rate
            rem -= cap
