Write a function sliding_windows(items: list, size: int) that returns a generator yielding successive contiguous windows of exactly `size` elements from items, stepping by one index each time (so items[0:size], then items[1:size+1], and so on through the last full window). Each yielded window must be a fresh independent list: mutating a previously yielded window must not change `items` and must not change later windows. If size <= 0, or size is greater than len(items), or items is empty and size > 0, yield nothing. Surface constraint: return a generator (lazy iterator), not a concrete list of all windows up front. Windows must still be materialised as lists when yielded (callers may index and assign into them).
