Write a function weave_lanes(lanes: list[list]) that returns a generator yielding elements in round-robin order across the sublists ("lanes"): yield the next unused element of lane 0, then of lane 1, and so on through the last lane, then repeat with the next unused element of each lane. When a lane has no remaining elements, skip it for that and all later rounds. Continue until every lane is exhausted. An empty lanes list, or a list of only empty lanes, yields nothing. Do not mutate any of the lane lists (callers may reuse them). Surface constraint: the function must be a generator that yields lazily ΓÇö it must not return a fully built list of all items up front. Callers may pull only the first few items from large lanes.
