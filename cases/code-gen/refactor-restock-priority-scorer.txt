Produce a clean function with the exact same name and signature:

    restock_priority(days_left, velocity, on_hand, shelf_cap, is_perishable) -> int

Behaviour (must match the original exactly):
- If any of days_left, velocity, on_hand, shelf_cap is None, return -1.
- If days_left < 0 or velocity < 0 or on_hand < 0 or shelf_cap <= 0, return -1.
- Let fill = on_hand / shelf_cap.
- Urgency points from days_left: 0 -> 50; 1..2 -> 40; 3..7 -> 25; 8..30 -> 10; else 0.
- Velocity points: >=20 -> 30; >=10 -> 20; >=3 -> 10; >0 -> 5; else 0.
- Stock points from fill: <0.1 -> 20; <0.25 -> 12; <0.5 -> 6; else 0.
- If is_perishable and days_left <= 7: add 15.
- If is_perishable and days_left == 0: add an extra 10 (stacking with the previous +15).
- Cap the running score at 100.
- Special override applied after the above: if on_hand >= shelf_cap and days_left > 7 and is_perishable is false, return 0.
- Otherwise return the (possibly capped) score.
- No I/O, no randomness, stdlib only.
