Implement a function rank_ready_parcels(csv_text: str, as_of: str) -> list[str].
csv_text is a CSV document with a header row and columns named exactly tracking, zone, ready_at, weight (extra columns may exist and must be ignored). Parse with csv.DictReader. as_of is a naive datetime string in the form YYYY-MM-DDTHH:MM:SS; parse it and every ready_at value with datetime.datetime.strptime using that same format.
For each data row: skip if tracking is missing/empty after strip; skip if zone is not a base-10 integer; skip if ready_at does not parse; skip if weight is not a float or is <= 0; skip if ready_at is strictly after as_of (ready_at equal to as_of is included). tracking may contain commas when the CSV field is quoted.
Rank included parcels by: zone ascending (int), then weight descending (float), then tracking ascending (lexicographic string compare on the stripped tracking). Return only the tracking strings in that order. An empty body (header only or no usable rows) returns []. Use csv and datetime from the standard library; no files or network.
