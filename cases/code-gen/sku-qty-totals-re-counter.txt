Implement a function sku_qty_totals(lines: list[str]) -> list[tuple[str, int]].
Each input string may contain zero or more inventory fragments matching this exact pattern (case-sensitive keywords): SKU=<id> qty=<n> where <id> is one or more ASCII letters or digits [A-Za-z0-9]+ and <n> is an optional ASCII minus sign followed by one or more digits (a base-10 integer, possibly negative). Between SKU=... and qty=... there must be one or more whitespace characters. Multiple fragments may appear on the same line; scan left to right and process every non-overlapping match.
Sum quantities per exact SKU string (case-sensitive; 'aa' and 'AA' are different). Omit any SKU whose final total is 0. Return the remaining pairs as (sku, total) sorted by total descending, then by sku ascending (lexicographic). Use re and collections from the standard library as appropriate. No other I/O.
